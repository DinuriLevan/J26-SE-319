# /ml

Placeholder folders for each team member's model code. These are intentionally empty — no shared scaffolding owns this directory beyond the folder structure itself.

- `handwriting/` — handwriting-recognition CNN
- `speech/` — speech/pronunciation model
- `spelling/` — spelling adaptive engine
- `math_memory/` — next-attempt models for Number Quest and Memory Match (trained on synthetic data; see `math_memory/README.md`)

Each owner is free to structure their own folder however suits their model (training scripts, notebooks, saved weights, requirements, etc.). See [../docs/CONTRIBUTING.md](../docs/CONTRIBUTING.md) for how your component's results and progress reach the shared backend.
